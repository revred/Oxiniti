# Oxiniti - Vibe Checker ✨

A fun, interactive CLI application that checks vibes! Created with Claude as a test of coding capabilities.

## About

The Vibe Checker is a colorful, interactive command-line tool that brings positive energy to your terminal. It's a playful demonstration of:
- Clean Python code structure
- Interactive CLI design
- Colorful terminal output using colorama
- Object-oriented programming
- User-friendly interface

## Features

- 🎨 Colorful terminal output
- 🎭 Multiple vibe types to discover
- 📜 Session history tracking
- ⚡ Interactive command interface
- 🎯 Simple and intuitive

## Installation

1. Clone the repository:
```bash
git clone https://github.com/revred/Oxiniti.git
cd Oxiniti
```

2. Install dependencies:
```bash
pip install -r requirements.txt
```

## Usage

Run the Vibe Checker:
```bash
python vibe_checker.py
```

### Commands

- `check <name>` - Check the vibe for a person (e.g., `check Alice`)
- `history` - View all vibes checked in this session
- `help` - Show available commands
- `quit` or `exit` - Exit the program

### Example

```
vibe> check Alice
==================================================
  VIBE CHECK for Alice
==================================================
        ✨ Immaculate Vibes ✨
     You're radiating pure excellence!
==================================================

vibe> check Bob
...

vibe> history
==================================================
  SESSION VIBE HISTORY
==================================================
1. Alice: ✨ Immaculate Vibes ✨
2. Bob: 🎉 Great Vibes 🎉

vibe> quit
Thanks for vibing! ✨ Stay positive! ✨
```
